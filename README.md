# Mahamudul Hasan — academic personal website (2026 refresh)

A modern, accessible, responsive, dependency-light static academic website. Content reflects research and academic activities known as of October 2026. Please review scholarly descriptions and publication metadata before publishing.

## Deploy
1. Copy `index.html` and the existing `CNAME` into your `mahamudul4.github.io` repository root.
2. Commit to a feature branch and open a pull request to `main`.
3. On merge, GitHub Pages will serve the new homepage; the previous homepage can still be accessed in Git history.

## Edit
- Text, visual styles and navigation live in `index.html` (no build step).
- Change links or add verified publications in the Publications section.
- **Retain the existing repository `profile.jpg` image**; the new page references that existing asset, which is not bundled here.
- Keep the existing `CNAME` file unchanged to retain the custom domain.
